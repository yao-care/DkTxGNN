## Sikkerhedsovervejelser

**Lægemiddelinteraktioner:** Der er identificeret 74 mulige interaktioner. De 20 viste i de indsamlede data er alle af moderat sværhedsgrad og omfatter hovedsageligt antidiabetika, hvor der kan være behov for tæt monitorering af blodsukker og evt. dosisjustering:
- Metformin, pioglitazon, acarbose
- Sulfonylurinstoffer: glimepirid, glipizid, glibenclamid, chlorpropamid, acetohexamid
- SGLT2-hæmmere: canagliflozin, dapagliflozin, empagliflozin, ertugliflozin
- GLP-1-receptoragonister og DPP-4-hæmmere: albiglutid, dulaglutid, exenatid, alogliptin
- Insuliner: humaninsulin, insulin aspart
- Andre: morfin, pegvaliase

For advarsler og kontraindikationer henvises til det godkendte produktresumé (SmPC).
