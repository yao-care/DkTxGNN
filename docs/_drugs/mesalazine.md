# Mesalazin: Fra colitis ulcerosa til leddegigt (reumatoid artritis)

## Sammenfatning i én sætning

Mesalazin (5-aminosalicylsyre) bruges oprindeligt til behandling af colitis ulcerosa og andre kroniske inflammatoriske tarmsygdomme.
TxGNN-modellen forudsiger, at lægemidlet kan have effekt ved **reumatoid artritis**, men der findes **ingen registrerede kliniske forsøg** og kun **indirekte litteratur** (primært om sulfasalazin, case-rapporter og bivirkningsrapporter), så evidensen er meget svag.

## Hurtigt overblik

| Punkt | Indhold |
|------|------|
| Oprindelig indikation | Colitis ulcerosa, inflammatorisk tarmsygdom, ulcerøs proktosigmoiditis (den danske godkendelsestekst er ikke tilgængelig i de indsamlede data) |
| Forudsagt ny indikation | Reumatoid artritis (rang 3 i modellens forudsigelser; se bemærkning nedenfor) |
| TxGNN-forudsigelsesscore | 99,57 % |
| Evidensniveau | L4 |
| Status på det danske marked | Markedsført |
| Antal markedsføringstilladelser | 1 |
| Anbefalet beslutning | Hold |

*Bemærkning:* Reumatoid artritis er valgt som fokus, fordi det er den eneste forudsagte indikation med et reelt, om end indirekte, litteraturgrundlag. De øvrige forudsigelser med højere score (fx medfødt hypotrikose med juvenil makuladystrofi, score 99,65 %, og slidgigt, score 99,63 %) har ingen kliniske forsøg og ingen plausibel mekanistisk begrundelse og vurderes som L5 / Hold.

## Hvorfor er forudsigelsen rimelig?

Data om mesalazins detaljerede virkningsmekanisme er ikke tilgængelige i de indsamlede data. Mesalazin er den aktive del af sulfasalazin og antages at virke antiinflammatorisk via hæmning af prostaglandin- og leukotrienveje, NF-κB-modulation og PPAR-gamma-aktivering.

Sulfasalazin er et etableret sygdomsmodificerende antireumatisk lægemiddel (DMARD) ved reumatoid artritis. Det spaltes af tarmbakterier til sulfapyridin og mesalazin. Den antireumatiske effekt tilskrives dog hovedsageligt sulfapyridin-delen og ikke mesalazin, så den direkte mekanistiske kobling er svag. Fælles inflammatoriske signalveje og den hyppige forekomst af ledmanifestationer ved inflammatorisk tarmsygdom giver en vis indirekte begrundelse, men den er spekulativ.

## Sikkerhedsovervejelser

- **Kontraindikationer/risikotilstande (fra videngrafen, ikke fra produktresuméet):** nyresygdom, interstitiel nefritis, lipoid nefrose, leversygdom, galdeblæresygdom, neutropeni, agranulocytose, anæmi (herunder makrocytær anæmi), pyloristenose og pyouretær.
- **Lægemiddelinteraktioner:** 393 interaktioner er registreret. Blandt de vigtigste er:
  - *Alvorlige:* cidofovir og humant botulinum-neurotoksin A/B-immunglobulin.
  - *Moderate:* NSAID (ketorolac, ibuprofen, celecoxib), azathioprin, nefrotoksiske stoffer (amphotericin B, amikacin, cisplatin, bacitracin, capreomycin) samt aciclovir.
- **Fra litteraturen:** Der er rapporteret overfølsomhedsreaktioner, herunder 5-ASA-induceret colitis og DRESS-syndrom med akut nyresvigt hos patienter med reumatoid artritis.

Se i øvrigt det godkendte produktresumé (SmPC) for fuldstændige sikkerhedsoplysninger.

## Konklusion og næste skridt

**Beslutning: Hold**

**Begrundelse:**
Der findes ingen kliniske forsøg, og litteraturen består af indirekte evidens (primært om sulfasalazin, hvis effekt hovedsageligt tilskrives sulfapyridin). Den høje TxGNN-score er ikke understøttet af kliniske data. Alle øvrige forudsagte indikationer (fx slidgigt, seboroisk keratose, pseudoakondroplasi) er vurderet som L5 / Hold uden plausibel mekanistisk begrundelse.

**For at komme videre kræves følgende:**
- Data om virkningsmekanisme (MOA) for mesalazin
- Advarsler og kontraindikationer fra det danske produktresumé (SmPC), som mangler i de indsamlede data
- Den godkendte indikationstekst for Asacol i Danmark
- Prækliniske eller eksplorative kliniske studier, der direkte undersøger mesalazin ved reumatoid artritis, herunder afklaring af 5-ASA's bidrag sammenlignet med sulfapyridin
- Vurdering af nyre- og overfølsomhedsrisici hos patienter med reumatoid artritis, som ofte samtidig får NSAID eller andre interagerende lægemidler
## Ansvarsfraskrivelse

Dette indhold er kun til forskningsformål og udgør ikke medicinsk rådgivning.
Klinisk validering er påkrævet før enhver klinisk anvendelse.
